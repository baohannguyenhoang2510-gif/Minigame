# ♠ Xì Dách Online ♥

Game Xì Dách nhiều người chơi trên trình duyệt, máy làm nhà cái. Kết nối trực tiếp giữa các người chơi (PeerJS / WebRTC), không cần server.

## Cách chơi
1. Mở trang game, nhập tên, bấm **Tạo phòng mới**.
2. Gửi **mã phòng 5 ký tự** cho bạn bè.
3. Bạn bè mở cùng trang, nhập mã và bấm **Vào phòng** (tối đa 7 người).
4. Chủ phòng bấm **Chia bài** để bắt đầu.

> Lưu ý: chủ phòng phải giữ tab mở; nếu chủ phòng thoát thì phòng sẽ đóng.
